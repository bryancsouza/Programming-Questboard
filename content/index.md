# Programming quests
*Exercises for becoming an awesome programmer*

This is a living document with a collection of programming exercises, sometimes also referred as quests. The goal of these quests is to provide interesting opportunities for novice programmers to practice their skills, while learning other topics and (hopefully) having fun at the same time. The exercises are designed in Python, but feel free to try to solve them with other programming language.

:::{note}
Each exercise clarifies the required skills needed at the beginning, together with the topic. For example, **A Study with Strings** requires basic knowledge of str, loops and if statements.

:::


# About the author

I'm a [lecturer at Radboud University](https://www.ru.nl/en/people/da-costa-souza-b), interested in making programming fun and inclusive. Except when stated otherwise, the exercises you can find on the website were designed by me. 

Because I care deeply about bias, the environment and ethical issues around the current generative AI models, no LLM was used in any way while building these resources and this website. This means that every quest was deeply thought of and designed to fit a specific level and interest that I find relevant.
